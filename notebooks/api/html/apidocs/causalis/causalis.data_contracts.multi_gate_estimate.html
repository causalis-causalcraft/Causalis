Bases: pydantic.BaseModel

Group-by-treatment effects with pointwise inference and joint covariance.

Effect arrays have shape (len(group_names), len(treatment_names)). treatment_names contains only active arms. Covariance axes use the group-major (group, treatment) product. Joint covariance does not imply simultaneous confidence intervals or multiplicity-adjusted significance.
